MY CARD VAULT — PRIVATE MVP

This is the first phone-ready prototype of My Card Vault.

IMPORTANT:
- It is currently a prototype, not a published app.
- Card data is stored in the browser on the device in this prototype.
- Purchase price is optional. Blank means UNKNOWN; the app does not invent a cost.
- Photos are stored as browser data in this prototype, so this is not yet the final storage system.

NEXT BUILD STEPS:

2. Add to iPhone Home Screen.
3. Add card editing/deleting.
4. Add card detail pages.
5. Add Sell/ROI dashboard.
6. Add better photo handling and backup.
7. Add AI card identification after the basic workflow is proven.
